# 独立后续研究

## RoboTwin

目标是相同数据、任务协议和测试种子下比较 π0.5、SmolVLA、X-VLA。启动前核环境、专家、模型版本、输入输出契约和成功谓词；先跑单任务闭环，再扩展自动采集与多任务。模型名称相同不代表权重、processor或动作语义兼容。此分支不阻断SO101，也不能代替LIBERO P1门禁。源码与权重遵循[来源和许可证](../third_party/PROVENANCE.md)。

## 真机 SO101

真机阶段需先定义设备/标定、唯一控制者、deadman、接管恢复、限位和急停，再收集真实数据并评估sim-to-real差异。仿真成功不等于实机安全。SO101 12维绝对关节契约见[契约](../inference/SO101_CONTRACT.md)；当前未启动真实follower。

阶段启动时写入协议、资产指纹、预算、停止条件和报告链接；不得创建空目录宣称支持。路线主索引：[roadmap](roadmap.md)。
