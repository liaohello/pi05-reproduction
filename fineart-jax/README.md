# FineART-VLA JAX 开发快照

这个分支供代码审查，包含 FineART-VLA 的 FP32 数据处理、权重映射、联合前向和 G0–G3 测试入口。K=5 的动作 loss 支持多样本 batch，包括 batch 长度等于 draw 数的情况。

当前 G3 的严格逐层数值验收仍有开放项。完整去噪预测、训练和公开端到端复现仍待验收。

完整测试依赖固定的参考树、权重、tokenizer、G0 锁文件及双运行环境。此分支提供源码、测试和锁文件生成工具。参考快照的公开获取路径待确认，第三方源码、权重、数据、运行证据和私有配置均留在 Git 之外。

了解来源与许可可查阅[迁移记录](../docs/migration-notes.md)和[第三方许可](../THIRD_PARTY_LICENSES.md)。
